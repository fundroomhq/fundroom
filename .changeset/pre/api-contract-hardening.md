Tighten the HTTP API to match its published contract. A known API path called with a method it does not support now answers `405 Method Not Allowed` with an `Allow` header instead of `404` (CORS preflight is unchanged). Email addresses are validated against one stricter pattern everywhere, also stated in the OpenAPI document: labels may not start or end with a hyphen and the local part is at most 64 characters, so an address such as `a@b-.com` is now refused. Workspace slugs document the reserved `v<digits>` rule, the embed handoff `assertion` must be a compact JWS, and `/auth/sso/finish` documents its error responses. Some query parameters have lower maximum lengths so that every valid request fits Node's 16 KB header limit: unsubscribe tokens 1024 characters (was 2048), chart tokens 1024 (was 4096) and the metrics `ids` list 1200 (was 2000); tokens the server issues are well below these. The web app turns off Zod's code generation before any schema is created, so the strict Content Security Policy (`require-trusted-types-for`) no longer reports a violation on load. The container image is now based on `gcr.io/distroless/nodejs24-debian13`.
